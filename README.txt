BILAL ENTERPRISES — FREE PORTFOLIO WEBSITE

Files:
- index.html: website content
- style.css: layout and styling
- script.js: hero slider and contact links

HOW TO CUSTOMIZE:
1. Open script.js in a text editor.
2. Add your real contact links in the CONTACTS section:
   whatsapp: "https://wa.me/923001234567"
   gmail: "mailto:yourname@gmail.com"
   instagram: "https://instagram.com/yourusername"
   linkedin: "https://linkedin.com/in/yourusername"
   facebook: "https://facebook.com/yourusername"
3. To replace the sample work cards, edit the work-card sections in index.html.
4. Replace the "Your photo goes here" placeholder by adding your photo to the folder and editing the portrait-placeholder element in index.html.

FREE PUBLISHING WITH GITHUB PAGES:
1. Create a free account at https://github.com/
2. Create a new public repository named exactly: YOURUSERNAME.github.io
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings > Pages, if Pages is not already enabled, and choose deploy from the main branch.
5. Your free website will be available at https://YOURUSERNAME.github.io (may take a few minutes).

No paid theme, subscription, or external paid service is required for this static website. The Google Fonts import uses an optional free service; the site still works if it is blocked.
